If you need a subheading, you need to differentiate the text apart from just changing the fonts. This can be done in two ways. The first way is by using the h1 tags. The headers range from 1 to 6, with 1 being the biggest and 6 being the smallest. From there, you can change the smaller details in the CSS.

The other way is by creating a div class and changing the font families, font size, color and weight if the font has it.
